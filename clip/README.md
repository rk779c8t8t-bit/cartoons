# EMINEM × TOLY SUMMER — анимационный клип

Итог: `output/eminem_toly_animated.mp4` — 1080×1920, 60 fps, 13.8 с, H.264 + AAC.

## Звук
Основа — музыка из второго видео (мэшап). Анализ (`00_analyze_audio.py`):
- темп ≈ 114.5 BPM, сетка долей `B(k) = 0.03 + 0.5242·k` с;
- 0–0.55 с — глиссандо-вступление, 0.55–2.65 — хук Toly Summer, **2.65 — дроп** (вход бочки) и куплет Eminem;
- 9.37–9.47 и 9.65–9.73 — стоп-тайм паузы, **9.99 — финальный удар**, 10.44 — добивка, 10.78 — конец музыки;
- после 10.8 с в исходнике идёт звук логотипа TikTok — он **не используется**.

`04_build_audio.py` добавляет только обработку самого трека: реверс-реверб «вдох» на 1 с перед первой нотой
и естественный реверб-хвост последней фразы. Посторонних звуков нет. В видео музыка начинается с 1.0 с.

## Персонажи
Лица взяты из кадров второго видео (`01_detect_faces.py`, MediaPipe Face Landmarker), затем
`02_stylize_characters.py` превращает их в постерную иллюстрацию: сегментация (волосы/кожа/одежда),
цел-шейдинг в 5 тонов через градиентную карту палитры клипа (чёрный → бордовый → красный → золото → крем),
тушевые линии, отдельная обработка одежды (белая рубашка Toly, тёмная куртка Eminem).
`03_prep_assets.py` готовит золотой rim-свет, карту проявления «из темноты» и векторные контуры-гравюру
(по тональным границам) для эффекта прорисовки золотыми линиями.

Полноростовые герои — векторные риги (Skia) с IK рук и ног: худи/шнурки/карман у Eminem,
рубашка/воротник/микрофон у Toly; позы меняются на долях, одежда покачивается.

## Движок
`engine.py` — 2.5D камера (орбита, крен, сдвиг объектива), перспективная проекция плоскостей
(homography через `setPolyToPoly`), easing, золотые линии с trim-анимацией.
`world.py` — персонажи, портреты, осколки, город (3 слоя параллакса), частицы с DOF, дым (FFT-шум), лучи, типографика.
`render.py` — сценарий и композитинг; пост: bloom из отдельного слоя свечения, вспышки на ударах,
хроматическая аберрация на акцентах, цветокор (бордовые тени, тёплые света), виньетка, зерно.

## Сборка
```
python3 01_detect_faces.py <work>          # нужен <work>/frames/*.png из второго видео (10 fps)
python3 02_stylize_characters.py <work>
python3 03_prep_assets.py <work> <work>/assets
python3 04_build_audio.py <work>/src/audio.wav <work>/mix.wav
./render_all.sh <work> ../output/eminem_toly_animated.mp4   # шрифты в <work>/fonts (Unbounded, Oswald)
```
Зависимости: skia-python, numpy, scipy, opencv, mediapipe, librosa, ffmpeg.
