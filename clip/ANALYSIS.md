# Анализ референса и как сделан клип

## Референс
- Референс: 576×1022, 30 fps, 76.2 с видео (2286 кадров). Картинка — полоса 16:9 (576×324, y=349–672) на чёрном фоне; ниже водяной знак TikTok; с 72.0 с — заставка TikTok.
- Фон: однотонные/градиентные заливки (жёлтый, оранжевый, розовый, малиновый, фиолетовый) с плёночным зерном; резкие смены сцен, иногда переход «прожиг».
- Текст впечатан в кадры (отделить нельзя), плюс эмодзи, стикеры и фото лиц.
- Шрифт: жирный широкий гротеск, только заглавные, белый, мягкая тёмная тень.
- Появление: побуквенное — каждая новая буква выскакивает маленькой и за ~0.1–0.15 с дорастает до полного размера с лёгким перелётом. Слова идут точно под вокал.
- Компоновка: 1–3 строки стопкой, по центру или по левому краю; короткие служебные слова мелким кеглем, ключевое слово крупнее; эмодзи после слова.
- Движение карточки: медленный наезд и лёгкий поворот. Уход: сплющивание по вертикали с растяжением и затуханием (~0.15 с), затем сразу следующая фраза.

## Реализация
1. `asr_ru.py`: локальное распознавание речи (бесплатная модель sherpa-onnx zipformer-ru), 3 прохода (микс; вокал по центральному каналу + полосовой фильтр; другие окна) → таймкоды токенов.
2. `align.py`: выравнивание присланного текста по распознанным символам (Нидлман–Вунш), фильтр выбросов, перенос таймингов между повторяющимися припевами (сдвиги 61.94 с и 12.38 с измерены по сходству аудио), интерполяция остальных слов → `timing.json`.
3. `make_bg.py`: чистая фоновая подложка из кадров референса — сохранены цвета, градиенты, смены сцен и их порядок; старый текст, стикеры, лица и водяной знак убраны размытием с маской → `bg.mp4` (72 с, повторяется по кругу под длину песни, без изменения скорости).
4. `render.py`: анимация текста (шрифт Rubik Black из Google Fonts, эмодзи Noto), тень, зерно, сборка 576×1022 + песня → `final_clip.mp4`.

## Формат результата
Полноэкранный 9:16, 1080×1920, без чёрных полей: подложка обрезана по центру до 9:16 и растянута на весь кадр.
