# «Пчёлки» 🐝 — максимально убогий 3D-клип

Готовое видео: `pchelki.mp4` (1080×1920, 9:16, 30 fps, оригинальная аудиодорожка без перекодирования).

## Как сделано
- **3D**: Three.js, low-poly пчёлы с flat shading и «пластиковым» бликом (`web/scene.js`). 6 видов: обычная, гигантская, крошечная, толстая, длинная, квадратная. Глаза разного размера, крылья-пропеллеры, короткие лапки.
- **Стиль 2005 года**: 3D рендерится в 540×960 без сглаживания и растягивается ×2 без фильтрации.
- **Текст**: тайминги слов получены распознаванием (Whisper small через faster-whisper), сверены несколькими прогонами и по энергии вокала; таблица `LYRICS` в `web/scene.js`.
- **Темп**: ~135.5 BPM — подпрыгивания и синхронный танец идут по долям.
- Каждый кадр — чистая функция времени, поэтому рендер параллелится.

## Пересобрать
```bash
npm i --ignore-scripts
# аудио из исходника: ffmpeg -i source.mov -vn -c:a copy song.m4a
for w in 0 1 2; do node render.js frames 30 0 99999 $w 3 & done; wait
ffmpeg -framerate 30 -i frames/f%05d.jpg -i song.m4a -map 0:v -map 1:a \
  -c:v libx264 -crf 24 -pix_fmt yuv420p -c:a copy -movflags +faststart pchelki.mp4
# отдельные кадры для проверки:
node render.js --preview preview 4.4 12.5 33.6
```
