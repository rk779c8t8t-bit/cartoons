# Lyric video «Ты горишь как огонь 2»

Автоматический конвейер: аудио → анализ → выравнивание текста по вокалу → анимация (Canvas в headless Chromium) → MP4 9:16.

Готовое видео: `../output/Ty_gorish_kak_ogon_2_lyric_video_9x16.mp4` (1080×1920, 30 fps, H.264, оригинальная песня целиком, звук AAC 320 kbps).

## Файлы
- `lyrics.txt` — текст песни: `[тип|исполнитель]` начинает секцию, одна строка = одна фраза, `(…)` — бэк-вокал.
- `asr_pass1.json`, `asr_pass2.json` — пословные тайминги из faster-whisper (модель small, второй проход с подсказкой словаря).
- `timing_fixes.json` — ручные правки для слов, которые распознавание не услышало.
- `prepare.py` — анализ аудио (бочка, доли, энергия по полосам) + выравнивание текста → `build/data.js`.
- `engine.html` — рендерер кадра: фоны со сменой цвета и вайпами, лучи, блёстки, мультяшное пламя, текст-стикеры, эмодзи к словам, плашки исполнителей, эффекты на «бум-бум», «замирает», «паранойя».
- `render.js` — захват кадров через Playwright → ffmpeg.
- `build.sh` — полная сборка в 4 потока.

## Сборка
```
pip install librosa soundfile
./build.sh song.mp3 asr_pass1.json,asr_pass2.json lyrics.txt build/full.mp4
```
