# SLAVA MARLOW × TOLY SUMMER — kinetic lyric video (1080×1920, 60 fps)

Готовый ролик: `output/slava_marlow_toly_summer_lyrics_1080x1920_60fps.mp4`
(H.264 High, 60 fps, 17.1 с; AAC-дорожка скопирована из присланного файла без перекодирования).

Стиль: чёрное пространство, белый шрифт с характером (Unbounded Black, Dela Gothic One),
огненно-оранжевые акценты, свечение, искры, motion blur, движение камеры на бочку.

## Синхронизация

1. Вокал отделён от музыки (Spleeter).
2. Пословные/побуквенные таймкоды — распознавание речи (GigaAM CTC + Whisper small, sherpa-onnx) скользящими окнами.
3. Уточнение по онсетам и спектрограмме вокала (напр. протяжное «(А!)» 15.33–15.7 с).
4. Темп **130 BPM**, бочки и огибающие — `src/analyze_audio.py`; они качают камеру, свечение и фон.

## Запуск

```bash
pip install numpy opencv-python-headless pillow librosa   # + ffmpeg
cd lyrics_video_toly
python3 src/analyze_audio.py      # если сменили аудио
python3 src/render.py             # полный рендер → output/ (~3.5 мин на 4 ядрах)
python3 src/render.py --stills 4.6 7.6 15.4      # проверочные кадры в previews/
python3 src/render.py --start 9 --end 12 --scale 0.5 --out previews/part.mp4
```

## Что менять

* **Музыка:** положите новый файл в `audio/fragment.m4a` (или поменяйте `"audio"` в timeline.json),
  запустите `analyze_audio.py`, поправьте тайминги.
* **Текст и тайминги:** `config/timeline.json` — поле `text` и `t` каждого слова. Размеры подгоняются по ширине автоматически.
* **Анимация строк:** функции `intro`, `v1`…`v8` в `src/scenes.py`; вспышки/тряска/искры — `_events()` там же.
* **Шрифты:** `fonts/` (Unbounded и Dela Gothic One — OFL; собраны из пакетов @fontsource в полный TTF с кириллицей).

## Инструменты

Python 3, NumPy, OpenCV, Pillow, librosa, FFmpeg/libx264. Движок (`src/engine.py`, `src/render.py`) общий
с соседним проектом `lyrics_video/`. Remotion не использовался: Python-рендер быстрее и полностью офлайн в этом окружении.
