Полная таблица: `output/validation.md`, `logs/validation.json`.

## Визуальная проверка
Проверка проводилась по контактным листам (`output/contact_sheet.jpg` — кадр в секунду) и по полноразмерным кадрам
каждой сцены — их просматривал Claude (анализ изображений). Видео целиком в реальном времени со звуком не просматривалось:
в среде нет плеера, звук проверен только численно (уровни, пики, отсутствие провалов).

| Критерий | Результат |
|---|---|
| Непрерывность внешности героев | ✅ все персонажи — одни и те же процедурные модели; формы, цвета, рисунок шерсти, рост совпадают с эталонами `assets/references/` |
| Цвета одежды | ✅ выцветшая голубая куртка и потёртые ботинки Рыжика, синяя куртка щенка, мятный комбинезон крольчихи, зелёный жилет лисёнка, бордовый жилет енота — во всех сценах |
| Ключевые действия | ✅ прибытие → насмешки → зонт → падение ветки → решение → рычаг и спасение → объятие и вина → примирение → финал |
| Артефакты | ✅ крупных нет; мелкие: лёгкий шум теней на ветках, на мокрой брусчатке в отдельных кадрах заметны блики |
| Вертикальная композиция | ✅ кадры построены под 9:16 |
| Надписи, водяные знаки | ✅ нет никакого текста (стрелки часов на башне заменены круглым окном, чтобы не получилась «буква») |
| Понятность без слов | ✅ эмоции переданы позами, ушами, бровями, глазами, ртом и музыкой |

## Исправления, сделанные по итогам проверок
- Инвертированный наклон корпуса (персонажи отклонялись назад вместо поклона) — исправлен.
- Ключи, вставленные внутрь шага, «телепортировали» персонажа к концу пути — введены канальные ключи `key_only`.
- Горизонтальные капли дождя → вертикальные; зонт привязан к лапе щенка.
- Ракурсы: в сцене 1 котёнок был спиной к камере, в сцене 6 камеру закрывала живая изгородь, в сцене 4 кролик был плохо виден,
  в сцене 5 щенок перекрывал кадр при беге — всё исправлено, сцены перерендерены.
- Щелчки в звуке ветра (фильтрация кусками) — переделано на плавное смешивание полос.

## Остающиеся ограничения
- Видео — **полноценная покадровая 3D-анимация** (суставы, мимика, походка, реквизит, камера), но качество — стилизованное:
  персонажи собраны из примитивов, мех шейдерный (без волосков), анимация без костей/физики ткани; не уровень крупной студии.
- Без GPU: EEVEE через программный OpenGL, 10 сэмплов; на быстрых движениях виден лёгкий шум размытия движения.
- Смех одноклассников передан музыкальной «хихикающей» фигурой ксилофона, а не звуком смеха — чтобы соблюсти запрет на голосоподобные звуки.
- Субъективная оценка звука на слух не проводилась (только инструментальная проверка уровней).
