# Библия персонажей — The Kitten Who Opened a Restaurant

Все персонажи — **оригинальные**. Они построены как процедурные 3D-модели
(`scripts/lbs3d/characters.py`, `scripts/lbs3d/world.py`). Параметры дизайна хранятся
в константах `MILO` и `MOM` и **не меняются между сценами**: каждая сцена использует один
и тот же объект персонажа, меняется только поза. Поэтому цвет глаз, шерсти, одежда,
пропорции и аксессуары физически не могут «уплыть» между кадрами.

Эталонные рендеры (из тех же 3D-моделей): `assets/references/`
`milo_front.png`, `milo_side.png`, `milo_three_quarter.png`, `mom_portrait.png`,
`noodle_reference.png`, `lineup.png`, `character_sheet.png`.

## Персонаж A — Milo (главный котёнок)

| Параметр | Значение (фиксировано) |
|---|---|
| Вид | маленький пушистый рыжий котёнок, антропоморфный, ходит на двух лапах |
| Рост | ≈ 0.46 у.е. без колпака (≈ 1/3 роста мамы) |
| Голова | большая круглая, радиус 0.12 (≈ 45% роста) |
| Шерсть | ярко-рыжая `RGB(1.00, 0.33, 0.02)`, мягкие полоски `RGB(0.75, 0.16, 0.01)`, мягкий «пушистый» шейдер (sheen + bump) |
| Мордочка | светло-кремовая `RGB(1.00, 0.80, 0.55)`: щёки, подбородок, низ лица |
| Глаза | огромные **янтарные** `RGB(1.0, 0.55, 0.03)`, чёрный зрачок, 2 белых блика |
| Нос | маленький розовый `RGB(1.0, 0.45, 0.55)` |
| Брови | маленькие тёмно-коричневые, подвижные |
| Рот | кошачий «ω», улыбка/открытый рот анимируются |
| Уши | треугольные, внутри розовые |
| Лапы | короткие, кремовые «варежки» |
| Хвост | пушистый рыжий, всегда виляет |
| Колпак | белый поварской, **немного великоватый** (пышная шапка из 6 «облачков»), чуть наклонён |
| Одежда | белая поварская куртка, 4 серые пуговицы, белый воротник; **светло-голубой фартук** с лямкой |

**Характер:** любопытный, энергичный, немного неуклюжий, добрый, смелый, гордится своей едой.

**Мимика (параметры `Cat.pose`)**: `eye_big` (удивление), `pupil` (испуг — зрачки сужаются),
`brow`/`brow_ang` (приподнятые/хмурые брови), `smile` (−1…1), `mouth` (открытый рот),
`eye_open` (моргание, подмигивание отдельным глазом), `ears` (настороженные/прижатые уши),
`hat_tilt` (колпак подпрыгивает), `squash` (мультяшное сжатие/растяжение), `flour` (покрыт мукой).

## Персонаж B — Мама-кошка

| Параметр | Значение |
|---|---|
| Вид | взрослая пушистая кремово-рыжая кошка, ходит на двух лапах |
| Рост | ≈ 1.6 у.е. (масштаб рига 2.6) |
| Шерсть | кремово-рыжая `RGB(1.0, 0.62, 0.30)`, светлые полоски; светлая грудка (пушистое «жабо») |
| Глаза | большие **зелёные** `RGB(0.2, 0.78, 0.25)`, ресницы |
| Уши | аккуратные, внутри розовые |
| Одежда | **нежно-розовый кардиган** с кремовыми пуговицами, **светлый кремовый фартук** |
| Хвост | изящный, пушистый |

**Характер:** добрая, заботливая, эмоциональная, любит готовить.

## Персонаж C — Ожившая макаронина (The Noodle)

| Параметр | Значение |
|---|---|
| Вид | большая масса золотистых спагетти: 11 нитей, сплетённых в гибкое «тело» |
| Материал | глянцевая золотистая паста `RGB(1.0, 0.66, 0.16)` с лаковым слоем |
| Голова | кудрявый клубок из 5 петель + 2 маленьких мультяшных глаза, розовые щёчки, маленькая улыбка |
| Ограничения | **нет зубов, когтей и пугающих деталей**; движения игривые и неуклюжие |

**Характер:** любопытная, игривая, неуклюжая, не агрессивная — она просто хочет попасть в тарелку.
В финале остаётся одна «оставшаяся» макаронина с глазками, которая обвивает тарелку.

## Правила согласованности

- Один риг на персонажа на весь фильм; нет генеративного «дрейфа».
- Запрещено: смена цвета глаз/шерсти, смена одежды, исчезновение колпака, лишние лапы,
  изменение формы мордочки или размеров персонажа.
- Мука (сцена 2) — временный эффект `flour` (0→1→0); к концу сцены 2 Milo стряхивает муку
  и снова рыжий, поэтому в сценах 3–9 он выглядит как в эталоне.
