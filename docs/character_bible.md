# Библия персонажей — «Над котёнком все смеялись»

Единый источник дизайна. В коде он закреплён словарём `CHARACTERS` в `scripts/blender/characters.py`:
каждый кадр фильма строится из **одних и тех же процедурных 3D-моделей**, поэтому форма, цвета, одежда и рост
не могут «поплыть» между сценами. Эталонные изображения: `assets/references/` (`<id>_front|threequarter|side|back|face.png`,
сводный лист `character_sheet.jpg`).

Общие правила для всех героев
- Пропорции «чиби»: крупная голова (≈45 % роста), короткие лапы, большие блестящие глаза с двумя бликами.
- Рост задаётся множителем `height` (котёнок = 1.0 ≈ 1.1 м в масштабе сцены, с ушами).
- Шерсть — шейдерный «мех»: мелкий вытянутый шум-бамп, sheen, светлая «пушистая» кромка по краю силуэта.
- Мимика: брови (наклон/высота), веки (раскрытие глаз), взгляд (зрачки), рот (shape keys улыбка/грусть + открытый рот),
  уши (поворот), хвост (shape keys вверх/вниз/влево/вправо). Без чрезмерной деформации лица.
- Анимация: суставы бёдер, корпуса, шеи, плеч, локтей, бёдер ног, коленей, стоп.
- **Запрещено** менять между сценами: цвета шерсти и глаз, одежду и обувь, рисунок пятен, рост, аксессуары.
  Единственные сюжетные изменения: рюкзак Рыжика (в руках → на спине → снят), грязь на левом ботинке Рыжика
  (появляется в сцене 6, енот её стирает в сцене 8), зонт щенка (сложен → раскрыт).

### Как обеспечена непрерывность
1. Все персонажи — код, а не генерация: один и тот же меш, материалы и пропорции в каждом кадре.
2. Эталонные изображения рендерятся тем же кодом (`scripts/generate_assets.py`) и служат контрольными листами.
3. Цвета заданы HEX-константами в одном месте; сцены не могут их переопределить.
4. Визуальная проверка: контактные листы финального видео (`output/contact_sheet.jpg`) сравнивались с эталонами
   (см. `docs/quality_report.md`).
