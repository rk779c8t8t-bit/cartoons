## Выбор способа генерации
- Приоритет A (API генерации видео) — **недоступен**: нет ключей.
- Приоритет B (API генерации изображений) — **недоступен**: нет ключей.
- Приоритет C (локальные диффузионные модели) — **нецелесообразен**: без GPU генерация видео/изображений на 4 ядрах CPU заняла бы
  дни и дала бы непостоянных персонажей.
- Приоритет D (локальный конвейер) — **выбран**, но не «картинки + движение камеры», а **полноценная 3D-анимация**:
  процедурные 3D-персонажи и окружение в Blender, покадровая анимация суставов, мимики, походки, реквизита и камеры,
  рендер EEVEE (программный OpenGL через EGL/llvmpipe, Cycles в этой сборке без денойзера).

Замеры: EEVEE 1080×1920, 10 сэмплов, каскадные тени 2048 — ~13 с/кадр при двух параллельных процессах;
весь ролик (1102 кадра с «хвостами» для растворений) ≈ 4 часа на CPU.
Шерсть сделана шейдером (шум-бамп + sheen + светлая кромка): частицы-волоски в программном EEVEE стоили ~11 с на объект и давали артефакты.

## Ограничения, мешающие «идеальной» автоматике
- Нет GPU → нет фотореалистичного Cycles с волосяным мехом и объёмными лучами; качество — стилизованный «премиальный» 3D-мульт
  с шейдерным мехом, а не уровень крупной студии.
- Нет внешних генераторов → персонажи и окружение смоделированы процедурно (примитивы + шейдеры), без скульптинга и риггинга костей.
- Рендер ~4 часа; при перезапуске готовые кадры переиспользуются.
- Если появятся ключи API видео-генерации, промты для каждой сцены уже лежат в `prompts/scenes/`, а референсы — в `assets/references/`
  (переменные перечислены в `.env.example`), но текущий конвейер их не требует.
