# ЗНАК — куплет Доры (анимированный клип)

Вертикальный музыкальный клип 1080×1920, 30 fps, 38.7 с, на куплет Доры из трека Toxi$ & Дора — «ЗНАК».
Готовое видео: **`out/znak_dora_verse.mp4`**.

## Сцены
| Кадры | Строка | Мир | Переход |
|------:|--------|-----|---------|
| 0–142 | «Выгляжу как попстар…» | Глянцевая обложка журнала «ЗНАК», силуэт в очках, прожекторы, вспышки папарацци. ПОПСТАР — розовый глянец, РОКСТАР — хром + электрические разряды, обложка «остывает» в голубой | Вспышка → свет фар |
| 142–267 | «Еду делать шоу…» | Ночная улица в перспективе: стены с окнами, неон, мокрый асфальт, дождь, машина. На «music don’t stop» — плеер с **настоящим спектром трека** | Полосы эквалайзера вытягиваются в лазеры (match cut) |
| 267–399 | «Эй, бэйби…» | Клуб: лазеры, диско-шар, толпа прыгает на доли, стробы. Текст вибрирует от баса. На «битком» кадр заполняется сердцами, звёздами, $, билетами SOLD OUT | Резкий cut (белый кадр → чёрный) |
| 399–524 | «Я вытру купюрой слёзы…» | Макро-проезд по гильошам вымышленной купюры, слеза падает и рассыпается блёстками, контровой свет проявляет голографический водяной знак | Сердце водяного знака заливает кадр розовым |
| 524–678 | «Окей, я могу влюбить…» | Глянцевое сердце бьётся в такт, на «НЕ ТОГО» трескается и разлетается. «Как же так?» — стоп-кадр, размытие, обесцвечивание | Размытие → облака |
| 678–813 | «Я хочу забыться…» | Космос: параллакс звёзд, облака, невесомость. FALLING IN LOVE растворяется в облаках частицами света | Звёзды втягиваются в центр |
| 813–940 | «Знаю, ты не веришь в гороскоп…» | Зодиакальный круг (все 12 знаков в правильном порядке). Две сферы «ТВОЙ»/«МОЙ» прокручивают знаки и останавливаются на «?» — конкретные знаки в тексте не названы, поэтому не выдумываются. «Плюс» — вспышка и световая линия | Сферы сливаются со вспышкой |
| 940–1162 | «Ты мной одержим…» | Круг разгоняется (speed ramp), вокруг вращаются знаки. ЗОДИА-ААК: буквы дрожат и растягиваются, на последнем слоге взрываются частицами; блёстки оседают, круг по инерции доворачивается, гаснет последняя звезда | Плавное затемнение 2 с; звук уходит эхом последнего такта |

Сквозные слои: световые блики, виньетка, VHS-строки и полоса трекинга, плёночное зерно, лёгкий пульс камеры на каждую долю.

## Структура
```
src/
  timing.ts            таймкоды слов (CUE), сетка долей (BEATS), границы сцен
  theme.ts             палитра, шрифты, тени/свечение
  fonts.ts             локальные шрифты (Unbounded, Russo One, Marck Script, JetBrains Mono, Noto Sans Symbols)
  util.ts              easing, beatPulse, speed ramp
  Video.tsx            сборка: аудио + сцены + общие оверлеи
  components/
    text/              Word (slam, pop, type, spin, rise, flicker, drop, glitch, zoom; выходы fade/blur/up/zoom/shatter), стили
    fx/                вспышки, стробы, зерно, VHS, виньетка, блики, электрические разряды
    bg/                обложка, силуэт, ночной город, машина, плеер, клуб, купюра, слеза, сердце, космос, зодиак
    particles/         блёстки, взрывы частиц, боке
  scenes/              S1…S8 — по сцене на строку
analysis/              скрипты анализа и таблица таймингов (см. analysis/README.md)
public/                аудио фрагмента (verse.wav), шрифты, текстуры зерна
scripts/               make_audio.py (нарезка звука + хвост), render.sh (полный рендер), stills.mjs (контрольные кадры)
```

## Запуск
```bash
npm install
npx remotion studio src/index.ts      # превью
./scripts/render.sh                   # → out/znak_dora_verse.mp4
node scripts/stills.mjs 45 300 1050   # контрольные кадры → out/stills/
```
В `remotion.config.ts` указан путь к Chromium этой среды — на другой машине строку `setBrowserExecutable` можно удалить.

Все изображения нарисованы кодом (SVG/CSS): нейросетевая генерация картинок в этой среде недоступна.
