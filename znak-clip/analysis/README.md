# Анализ аудио

**Трек:** Toxi$, Дора — «ЗНАК» (3:36, 44.1 kHz, 320 kbps).

## Как искали куплет
1. `transcribe.py` — распознавание речи (faster-whisper, модель *small*) с таймкодами по словам.
   Полная расшифровка песни в репозиторий не сохраняется — использовались только таймкоды.
2. Поиск опорных слов («попстар», «рокстар», «водяной», «звёзд», «маньяк») → куплет Доры: **2:19.76 – 2:55.46**.
3. `beats.py` — librosa: темп **≈110 BPM** (шаг доли 0.545 с), сетка долей, онсеты, громкость.

## Фрагмент клипа
* Начало: **139.16 с** (доля прямо перед первым словом — место для вспышки камеры).
* Конец: **177.89 с** (сильная доля; ~2.5 с на плавный финал).
* Длительность: **38.73 с = 1162 кадра при 30 fps**. Аудио — оригинал без изменения скорости/тона.
* Финал: оригинал звучит до **175.40 с** — сразу после удара на «-ААК» и до вступления следующего вокала (≈175.44 с),
  дальше только реверберационный хвост последних 1.2 с, плавно уходящий в тишину к 38.4 с клипа.
  Голос следующего исполнителя в клип не попадает. Сборка: `python3 -I scripts/make_audio.py znak_full.mp3 public/verse.wav`.
