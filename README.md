# Little Big Stories — «The Kitten Who Opened a Restaurant»

Вертикальный мультфильм для YouTube Shorts: **36 секунд, 1080×1920, 30 fps, без слов**.

Маленький рыжий котёнок Milo мечтает стать шеф-поваром. Он остаётся один на кухне,
устраивает облако муки, оживляет гигантскую макаронину, убегает от неё по всей кухне, но понимает,
что она просто хочет попасть в тарелку, и превращает её в шедевр. Мама приходит домой, пробует… и просит добавки.

**Готовый ролик:** [`output/final_short.mp4`](output/final_short.mp4) · лёгкое превью: `output/preview.mp4` ·
контактный лист кадров: `output/contact_sheet.png`

---

## Как сделан мультфильм (честно)

В среде производства **не было** ни GPU, ни ключей к AI-генераторам, а сеть до их API была закрыта
(подробно — `docs/technical_audit.md`). Поэтому ролик **не сгенерирован нейросетью**. Он создан так:

| Этап | Технология |
|---|---|
| Персонажи, кухня, реквизит | процедурное 3D-моделирование кодом в **Blender 5.2** (`bpy` как Python-модуль) |
| Анимация | каждый кадр вычисляется кодом: позы, мимика, сквош-стретч, мультяшная физика, 3–4 камеры на сцену |
| Рендер | **Cycles** (трассировка пути, CPU), 540×960 @ 8 spp + шумоподавление OpenImageDenoise |
| Апскейл / цвет | FFmpeg: Lanczos до 1080×1920, лёгкая резкость, насыщенность |
| Музыка | оригинальная партитура, синтез с нуля на numpy/scipy (ксилофон, маримба, пиццикато, пианино, струнные, медные, колокольчики, ударные) |
| Шумы и эмбиенс | 45 синтезированных звуковых эффектов, привязанных к событиям на экране; комнатный тон кухни |
| Монтаж | FFmpeg, H.264 High + AAC 192k, громкость −14 LUFS / −1.5 dBTP |

Это настоящая 3D-анимация (а не «оживление» статичных картинок), но **не** AI-видео.

## Установка

Требуется **Python 3.13** (колёса `bpy` 5.2 собраны под CPython 3.13), FFmpeg и ~3 ГБ места.

```bash
sudo apt install ffmpeg imagemagick        # imagemagick необязателен (листы-монтажи)
pip install -r requirements.txt            # bpy ≈ 400 МБ
```

GPU не нужен. На 4 ядрах CPU полный рендер занимает ≈ 2–2.5 часа.

## Настройка API (необязательно)

Конвейер полностью локальный и **не делает платных запросов**. Если появятся ключи AI-генераторов,
скопируйте `.env.example` в `.env` и заполните нужные переменные — `audit_environment.py` их обнаружит
(значения никогда не выводятся). Промты из `prompts/` и референсы из `assets/references/` готовы для
image-to-video сервисов; адаптеры к платным API намеренно не включены, пока их нельзя проверить.

## Запуск

```bash
python3 run.py --dry-run      # аудит + план работ: ничего не рендерит, никаких платных запросов
python3 run.py                # весь конвейер: audit → deps → refs → render → audio → assemble → validate → report
```

Прогресс выводится в терминал и пишется в `logs/run.log`; выполненные шаги — в `logs/run_state.json`.
**Повторный запуск после сбоя:** просто запустите ту же команду — готовые кадры пропускаются.

### Пересоздание одной сцены

```bash
python3 run.py --scene 4            # перерендерить только сцену 4, затем пересобрать и проверить ролик
python3 run.py --scene 2,7 --draft  # быстрый черновик (270×480) в assets/generated/draft, финал не трогается
```

### Отдельные шаги

```bash
python3 run.py --only audio        # пересоздать музыку и эффекты
python3 run.py --only assemble     # пересобрать видео из готовых клипов
python3 scripts/animate_scenes.py --scenes 3 --frames 60-89 --force   # перерендерить диапазон кадров
python3 scripts/animate_scenes.py --scenes all --keyframes 0.5,2,3.5 --width 270 --height 480  # раскадровка-кадры
```

## Проверка результата

```bash
python3 scripts/validate_video.py   # технические проверки + output/contact_sheet.png
python3 -m pytest -q tests
```

Проверяются: наличие и размер файла, чтение FFprobe, видео- и аудиопотоки, 1080×1920, 9:16, 30 fps,
длительность 30–40 с, H.264/AAC, синхронность длительностей, отсутствие чёрных кадров, «замёрзших»
участков, клиппинга и тишины, громкость −14 LUFS, наличие склеек на границах 9 сцен и движения в каждой
сцене, отсутствие мерцания. Визуальные критерии (персонажи, текст, конечности) проверяются вручную по
контактному листу — см. `docs/quality_report.md`.

## Частые ошибки

| Проблема | Решение |
|---|---|
| `No module named bpy` | нужен Python 3.13: `pip install bpy==5.2.3` |
| `CUEW initialization failed` в логе | это нормально: CUDA нет, Cycles работает на CPU |
| EEVEE: `libEGL.so.1` / очень медленно | проект использует Cycles; EEVEE без GPU не нужен |
| Рендер прервался | запустите ту же команду снова — существующие кадры пропускаются |
| `missing scene clips` при сборке | сцена не дорендерена: `python3 run.py --scene N` |
| Слишком долго | `--draft` для проверки, или уменьшите `FINAL` в `run.py` |
| Нет места на диске | удалите `assets/generated/frames/` после сборки клипов (их можно пересоздать) |

## Авторство и лицензии

Персонажи, модели, анимация, музыка и звуки созданы с нуля кодом этого репозитория — без сторонних
сэмплов, изображений, видео и без копирования существующих персонажей.
