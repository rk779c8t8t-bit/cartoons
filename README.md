# «Гикаю» — анимированный клип (кинетическая 3D-типографика)

Готовый ролик: **`out/gikayu_clip_1080p.mp4`** — 1920×1080, 16:9, 30 fps, H.264 + AAC 320 kbps, 36.08 с.

Фрагмент песни: **54.80 → 90.88 с** оригинального MP3. Он начинается в тихом брейке перед «Ты слушаешь»
(бас-дроп приходится ровно на «ХУ*НЮ», 58.04 с) и заканчивается в конце секции, где пропадает бас.
Следующая строка («Мои мозги…») начинается в 90.94 с и в клип не входит. Звук не менялся,
по краям только 10/20 мс микрофейд против щелчков на склейке.

## Как устроено

| Папка | Что внутри |
|---|---|
| `web/clip.js` | вся анимация: three.js-сцена, 3D-буквы, частицы, свечение, VHS/RGB-глитч, 7 сцен |
| `web/timing.json` | таймкоды каждого слова, темп (148 BPM), сетка долей; единый источник синхронизации |
| `web/assets/` | шрифты Unbounded/Montserrat (кириллица → three.js typeface), 3D-эмодзи Fluent (MIT) |
| `render/render.mjs` | покадровый рендер в headless Chromium → ffmpeg |
| `tools/` | конвертер шрифтов, сборка контактных листов |
| `analysis/` | распознавание слов (Whisper), анализ бита и атак голоса, спектрограмма, кадры референса |

Каждый кадр — чистая функция времени песни `T`, поэтому кадры можно рендерить в любом порядке,
и они всегда совпадают со звуком. Каждый финальный кадр усредняется из 4 подкадров со сдвигом
на долю пикселя и во времени: это даёт сглаживание и настоящий motion blur.

### Синхронизация
1. Whisper small (faster-whisper) с пословными таймкодами нашёл строки в треке.
2. Атаки голоса (спектральный поток в полосе 250–3500 Гц) уточнили начало слов; каждое «ГИ» стоит
   на своей атаке (шаг 0.405 с, со смещением на 1/16 относительно доли).
3. Темп 148 BPM и фаза сетки подобраны по onset-огибающей; удары бочки управляют зумом, свечением
   и частицами; отдельные события (вспышки, тряска, глитч) привязаны к словам в `web/timing.json`.

## Сцены
1. **Ты слушаешь ху\*ню**: «СЛУШАЕШЬ» проявляется из темноты по буквам, на дропе «ХУ\*НЮ» вылетает
   из-за камеры, вспышка, RGB-глитч, взрыв искр, буквы дрожат и раскидываются басом.
2. **Детка… Bluetooth**: «ДЕТКА» плавно масштабируется, «ПОДКЛЮЧИТЬСЯ» подключается мерцанием по буквам,
   3D-значок Bluetooth с волнами сигнала, полоса CONNECTING → CONNECTED, вспышка значка, пролёт сквозь камеру.
3. **Я реальный белый**: «РЕАЛЬНЫЙ» поднимается из глубины, белая вспышка на «БЕЛЫЙ», поворот, как у грани куба,
   «ВКУС» с желейной упругостью, 3D-леденец.
4. **Каким бы я ни был**: фрагменты с глитч-появлением, «ТОЧНО» врезается в камеру, на «НЕ ПИ\*ЖУ» сильный
   глитч, тряска, буквы разлетаются и собираются обратно.
5. **И где бы я ни был, я всегда**: камера летит от слова к слову в пространстве, «ВСЕГДА» с объёмным вращением.
6. **Ги-ги-ги-ги-гикаю, да** (главный момент): каждое «ГИ» на своём ударе прилетает, сталкивается
   и подпрыгивает, мини-копии «ГИ», 💥; огромное «ГИКАЮ» почти во весь экран, слоги прыгают; «ДА» штампом.
   Повтор в треке («Я ги-ги-ги-ги-ги-гикаю, да») сделан полётом через тоннель из «ГИ»
   и прыгающими волной буквами на фоне бегущих строк.
7. **Я гикаю, пока я вообще не отключусь**: вокруг «Я ГИКАЮ» вращаются светящиеся символы,
   на «ОТКЛЮЧУСЬ» картинка ломается (глитч, блоки, эхо, буквы осыпаются, батарея садится, NO SIGNAL),
   на последнем ударе экран гаснет, как старый телевизор.

## Пересборка

```bash
npm install
node tools/make-fonts.mjs
# аудио-фрагмент
ffmpeg -i "Платина – Гикаю.mp3" -af "atrim=start=54.8:end=90.88,asetpts=PTS-STARTPTS,afade=t=in:d=0.01,afade=t=out:st=36.06:d=0.02" -c:a aac -b:a 320k out/audio.m4a
# видео (≈1 ч на 4 ядрах без GPU)
node render/render.mjs --fps 30 --sub 4 --workers 1 --out out/video_noaudio.mp4
# сборка
ffmpeg -i out/video_noaudio.mp4 -i out/audio.m4a -map 0:v -map 1:a -c:v libx264 -preset slow -crf 15 -pix_fmt yuv420p -c:a copy -movflags +faststart -shortest out/gikayu_clip_1080p.mp4
```

Быстрые стоп-кадры: `node render/render.mjs --stills 3.7,18.4 --scale 0.5` (время от начала клипа).
Просмотр в браузере с музыкой: открыть `web/index.html?play` через любой локальный сервер, кликнуть по странице.
