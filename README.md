# TOLY SUMMER × EMINEM — музыкальный эдит

**Финальная версия (v2):** `output/eminem_toly_final.mp4` — 1080×1920, 60 fps, 15 с, H.264 + AAC.
Старая мультяшная версия (v1) оставлена для истории: `output/eminem_toly_animated.mp4`.

## Принцип v2
Оригинальные фотографии не изменяются: никакой стилизации, анимации рта или мимики, никаких искусственных тел.
Каждая фотография — плоская карточка, которая двигается целиком: масштаб, поворот, сдвиг, панорама внутри рамки,
растворение, вылет за границы кадра. Вырезанная копия тех же пикселей (`assets/photos/*_cut.png`) используется
только как слой, чтобы текст мог проходить «за» человеком.

## Файлы проекта
| Файл | Что делает |
|---|---|
| `src/prep_photos.py` | Кроп + апскейл (Lanczos) оригиналов, маска человека (GrabCut) для слоёв |
| `src/audio.py` | Анализ музыки (≈117.5 BPM, сетка долей, тайминг слогов) + сборка саундтрека |
| `src/edit.py` | **Эдит v2**: сцены, движения фото под бит, кинетическая типографика, переходы |
| `src/typo.py` | Движок кинетической типографики (побуквенные входы/выходы, капсулы, глитч) |
| `src/fx.py` | Фон и графика: лучи, кольца, свет, частицы, прожекторы, полутон |
| `src/core.py` | Тайминг, easing, бит-функции, палитра |
| `src/render.py` | Параллельный рендер + сборка FFmpeg |
| `src/scenes.py`, `src/character.py`, `src/build_chars.py` | v1 (мультяшная версия), не используется в v2 |

## Пересборка
```
pip install opencv-python-headless numpy pillow librosa scipy soundfile skia-python
python3 src/prep_photos.py && python3 src/audio.py
FPS=60 MOD=edit OUT=eminem_toly_final.mp4 python3 src/render.py
```
Предпросмотр отдельных кадров: `MOD=edit python3 src/test_frames.py 3.4 7.9 13.8`.
