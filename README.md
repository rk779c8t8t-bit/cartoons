# «Депутат» — музыкальный клип 1080×1920

Готовый ролик: **[out/clip.mp4](out/clip.mp4)** (H.264, 1080×1920, 9:16, 30 FPS, 21.93 с; звук — оригинальная AAC-дорожка без перекодирования, побитово совпадает с исходником).

## Анализ трека
* Язык — русский. Жанр/настроение: сатирический поп/хип-хоп, дерзкий и ироничный.
* Темп ≈ 129 BPM (доля ≈ 0.465 с), первый бит 1.02 с — с него начинается вокал.
* Структура: 0–1 с вступление → 1–5 с «огонь» (тихо) → ~5.0 с вход полного бита → 11–12 с короткие брейки → 16.5–17.5 с брейк → 18.0 с финальный удар → 18.5–21.9 с тишина (аутро).

## Текст (распознан автоматически)
```
Ты горишь, как огонь, — гори!
Я горю тоже!
Я выбираю костюмчик подороже,
Часики «Ролекс» — миллион баксов.
Сегодня не буду слишком выделяться.
Я очень рад: я депутат,
Послушный и верный солдат.
Важная миссия — в Единой России:
Чей-то тесть, чей-то сват, чей-то брат.
```
Как получен: Whisper turbo и GigaAM v2 (оффлайн, бесплатно) + сравнение вариантов спорных мест по CTC-правдоподобию.
Наименее уверенные места (вокал сильно обработан): «гори / горит», «Ролекс / ролик», «миллион / миллионов», «Важная / Ваша», последняя строка.
Если слышите иначе — исправьте `lyrics/lyrics.txt` и пересоберите (см. ниже): тайминги пересчитаются автоматически.

Тайминги — пословные и побуквенные (принудительное выравнивание CTC-моделью GigaAM): `lyrics/timing.json` (можно править вручную), а также `lyrics/lyrics.lrc` и `lyrics/lyrics.srt`.

## Визуальная концепция
Сатирический «поп-арт-нуар» в духе советского плаката: красный, золото, чернила, кремовая бумага; плёночное зерно, виньетка, блики.
Все изображения нарисованы кодом (Canvas 2D), без стоковых материалов.

| Время | Строка | Сцена | Переход |
|---|---|---|---|
| 0–5.05 | Ты горишь… / Я горю тоже | Горящий город, силуэт героя; на «гори!» вспышка, на «Я горю» загорается сам герой | — |
| 5.05–6.87 | Костюмчик подороже | Бутик: костюм под прожектором, ценники множатся на «подороже» | вспышка (вход бита) |
| 6.87–8.89 | Часики «Ролекс» | Золотые часы, секундная стрелка тикает в бит, денежный дождь усиливается на «миллион» | нарезка полосами |
| 8.89–10.84 | Не буду выделяться | Серая толпа; золотой костюм героя сереет на «слишком выделяться» | зум |
| 10.84–12.33 | Я депутат | Здание с колоннами, прожекторы, руки голосуют в бит | красная диагональная шторка |
| 12.33–13.97 | Послушный солдат | Марионетка в костюме марширует в бит, на «солдат» — фуражка и честь | вспышка |
| 13.97–15.97 | Важная миссия | Конструктивистский плакат: лучи, восход, триколор | нарезка |
| 15.97–21.9 | Чей-то тесть, сват, брат | Семейное древо: на каждом слове вырастает ветка и портрет; на 18.0 денежный салют, в тишине древо разрастается, кадр плавно затемняется (не до чёрного) | круговое раскрытие |

Типографика: обычные слова — Oswald, акцентные (в `lyrics.txt` отмечены `*…*`) — Unbounded золотом с объёмной тенью и ударной волной. Слово появляется в момент начала пения (масштаб/сдвиг/поворот), буквы заливаются золотом по побуквенным таймингам, акценты пульсируют в бит; на экране только текущая фраза.

## Структура проекта
```
src/audio/song.m4a     аудио, извлечённое из исходного .mov
src/clip.html, clip.js рендерер клипа (Canvas 2D); data.js — тайминги + анализ аудио
src/fonts/             шрифты (SIL OFL)
lyrics/                текст, timing.json, .lrc, .srt
tools/                 скрипты пайплайна
out/clip.mp4           готовый клип
```

## Повторный запуск
Нужно: ffmpeg, Python 3, Node.js и Playwright с Chromium.
```bash
pip install sherpa-onnx kaldi-native-fbank onnxruntime soundfile librosa
tools/get_models.sh                    # ~1.5 ГБ моделей с GitHub (sherpa-onnx)
tools/prepare_audio.sh my_song.mov     # аудио -> src/audio/song.m4a + рабочие wav
python3 tools/transcribe.py            # (опционально) черновое распознавание
#   -> правите lyrics/lyrics.txt
python3 tools/align.py                 # пословные тайминги -> lyrics/timing.json
python3 tools/analyze.py               # биты/энергия + тайминги -> src/data.js
node tools/render.js out/clip.mp4      # рендер MP4 (~2 мин)
```
Просмотр в браузере со звуком: откройте `src/clip.html` (клик по кадру — старт/пауза; `?t=12.5` — кадр в момент 12.5 с).
Кадры для проверки: `tools/sheet.sh "1,5.5,9" sheet.jpg`.

Время сцен задаётся в массиве `SCENES` в `src/clip.js`; если правите `timing.json` вручную, после этого запустите только `analyze.py` и `render.js`.
