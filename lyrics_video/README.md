# SLAVA MARLOW — kinetic lyrics visualizer (1080×1920, 60 fps)

Вертикальная кинетическая типографика под приложенный фрагмент (16.2 с).
Всё рендерится кодом: Python + NumPy + OpenCV + Pillow, сборка видео — FFmpeg.

Готовый ролик: `output/slava_marlow_lyrics_1080x1920_60fps.mp4`
(H.264 High, yuv420p, 60 fps, оригинальная AAC-дорожка скопирована без перекодирования).

## Важно про текст

В приложенном аудио спеты строки 1–5 брифа — файл обрывается на «агония»:

| # | Строка | Время, с |
|---|--------|----------|
| 1 | Ты горишь, как огонь, я, у меня агония | 0.15 – 4.0 |
| 2 | Это любовь или это паранойя? | 4.03 – 7.05 |
| 3 | Ля, ля-ля (Ля, ля-ля) | 7.08 – 9.4 |
| 4 | Ты горишь, как огонь, я (Ля, ля-ля; round…) | 9.75 – 12.3 |
| 5 | Ты горишь, как огонь, я, у меня агония | 12.32 – 16.2 |

Строк 6–8 («Это любовь…», «Ля, ля-ля…», финальное «Ты горишь, как огонь, я») в файле нет,
поэтому в ролик они не добавлены (иначе текст разошёлся бы со звуком). Финальный удар
(распад букв на частицы + вспышка) сделан на последнем слове, которое реально звучит.
Если дать более длинный аудиофайл — добавьте строки L6–L8 в `config/timeline.json`
и опишите их анимацию в `src/scenes.py` (можно переиспользовать функции строк 2–3).

## Как синхронизировано

1. Вокал отделён от музыки (Spleeter 2stems).
2. Слова найдены распознаванием речи (Whisper small + GigaAM через sherpa-onnx) скользящими окнами.
3. Точные начала слов/слогов — по онсетам и огибающей отделённого вокала, проверено на спектрограммах.
4. Темп и удары — `src/analyze_audio.py` (librosa): **156.5 BPM**, удар ≈ 0.383 с;
   огибающие бочки/громкости по кадрам управляют пульсацией камеры, свечения и фона.

## Структура

```
audio/fragment.m4a        исходная аудиодорожка (AAC, извлечена из присланного .mov без перекодирования)
config/timeline.json      ВСЕ тайминги слов и слогов — правьте здесь
analysis/analysis.json    биты, бочки, огибающие (генерируется analyze_audio.py)
src/analyze_audio.py      анализ аудио
src/scenes.py             хореография: что, где и как двигается в каждой строке + события (вспышки, тряска, глитч, искры, кольца)
src/engine.py             движок: текст по буквам, огненные/металлические заливки, объём, свечение, частицы, глитч
src/render.py             сборка кадра (фон с дымом и пламенем, марево, камера, bloom, хроматика) и экспорт
src/contact.py            контактные листы для проверки кадров
fonts/                    Inter Display Black / Black Italic / ExtraBold, JetBrains Mono ExtraBold (OFL)
```

## Повторный рендер

```bash
pip install numpy opencv-python-headless pillow librosa   # + ffmpeg в системе
cd lyrics_video
python3 src/analyze_audio.py          # только если сменили аудио
python3 src/render.py                 # полный рендер → output/ (≈4 мин на 4 ядрах)
```

Быстрые проверки:

```bash
python3 src/render.py --stills 1.4 3.7 6.5          # PNG-кадры в previews/
python3 src/render.py --start 3 --end 5 --scale 0.5 --out previews/part.mp4
python3 src/render.py --crf 14                       # выше качество/битрейт
```

Каждый кадр — чистая функция времени, поэтому рендер параллелится по процессам
(`--workers N`), а любой кусок можно перерендерить отдельно.

## Что где менять

* Сдвинуть слово — `t` / `syl` в `config/timeline.json`.
* Сила вспышек, тряски, глитча, искр — функция `_build_events()` в `src/scenes.py`
  (`flash(...)`, `shake(...)`, `glitch_ev(...)`, `sparks(...)`, `ring(...)`, `puff(...)`).
* Позиции/размеры/стили слов — функции `line1`…`line5` и `L1` в `src/scenes.py`.
* Палитра огня — `FIRE_LUT` / `METAL_LUT` в `src/engine.py`.

## Инструменты

Python 3, NumPy, OpenCV, Pillow, librosa, FFmpeg/libx264.
Для разметки таймингов (не нужны для рендера): Spleeter, sherpa-onnx (Whisper small, GigaAM CTC).
